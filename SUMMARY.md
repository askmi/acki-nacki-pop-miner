# Acki Nacki — краткое описание механики майнинга

## Общая идея

Майнинг в Acki Nacki происходит непрерывно и разбит на **эпохи**. Размер награды зависит от уровня виртуального **Motherboard (Monoboard)**, который пользователь постепенно улучшает с помощью ресурса **Boost**.

Все добытые токены сначала находятся в состоянии **Locked** и становятся доступными только после процедуры **Burn** Motherboard.

---

# Эпохи

## Что такое эпоха

Эпоха — это период продолжительностью **330 секунд (5 минут 30 секунд)**.

За каждую эпоху пользователь может выполнить **70 действий (тапов)**.

После выполнения этих действий эпоха считается завершенной, и начисляется награда за майнинг.

Схема выглядит так:

```
330 секунд
      │
      ▼
70 действий (тапов)
      │
      ▼
Завершение эпохи
      │
      ▼
Начисление награды
```

За сутки проходит примерно:

- 24 часа
- 15 840 эпох в год
- около **262 эпох в сутки**

---

# Награда

Размер награды за одну эпоху зависит от:

- уровня Motherboard;
- общей суточной эмиссии сети;
- количества активных майнеров.

По мере роста числа участников награда постепенно уменьшается (аналог халвинга).

Пример:

- в начале работы сети можно было получать около **60 NACKL** за эпоху;
- сейчас даже при почти максимальном уровне Motherboard награда составляет примерно **5.5 NACKL** за эпоху.

Ожидается дальнейшее снижение наград после очередного уменьшения эмиссии.

---

# Motherboard (Monoboard)

Motherboard — виртуальная плата, определяющая эффективность майнинга.

Особенности:

- состоит из **72 деталей**;
- каждая улучшенная деталь повышает уровень Motherboard;
- чем выше уровень — тем выше награда за эпоху;
- каждое следующее улучшение требует значительно больше Boost.

Например:

- очередной апгрейд может требовать около **960 000 Boost**.

---

# Boost

Boost — ресурс, необходимый для улучшения Motherboard.

## Получение

За сутки можно получить **5 пакетов Boost**.

Каждый пакет становится доступен примерно раз в **1 час 35 минут**.

То есть для максимального прогресса необходимо заходить в приложение примерно каждые полтора часа и забирать очередной пакет.

---

## Накопительный бонус

Если ежедневно собирать все 5 пакетов, количество получаемых Boost постепенно увеличивается.

Пример:

```
День 1 → 100 Boost за сбор
День 2 → 108
День 3 → 116
...
```

Если пропустить день и не собрать все Boost:

- серия прерывается;
- накопительный бонус уменьшается;
- прогресс откатывается.

---

# Locked токены

Все намайненные токены сначала находятся в состоянии **Locked**.

Они:

- принадлежат пользователю;
- учитываются в балансе;
- но не могут быть переведены или проданы.

---

# Burn Motherboard

Для разблокировки накопленных токенов необходимо выполнить **Burn** Motherboard.

Во время Burn:

- текущий Motherboard уничтожается;
- все Locked токены становятся доступными;
- Motherboard создается заново;
- процесс улучшения начинается сначала.

Таким образом Burn одновременно:

- разблокирует токены;
- запускает новый цикл развития Motherboard.

---

# Торговля токенами

После Burn токены становятся полноценными токенами сети.

Их можно:

- переводить между пользователями;
- продавать другим участникам сообщества.

На данный момент основная торговля происходит через P2P.

После запуска официального Bridge токены можно будет выводить во внешние сети и на биржи.

---

# Цена

Внутри сообщества уже существуют сделки между пользователями.

По имеющейся информации:

- была единичная сделка примерно по **$1** за токен;
- обычные P2P-сделки проходят примерно по **$0.00020–0.00025** за токен.

Это не является официальной рыночной ценой, а отражает текущие сделки внутри сообщества.

# История запуска

- Майнинг стартовал **7 октября**.
- Предмайнинга не было.
- Команда не получала отдельного распределения токенов.
- При создании кошелька бесплатные токены не начисляются.

# Полный цикл

```
Старт майнинга
        │
        ▼
Каждые 330 секунд начинается новая эпоха
        │
        ▼
Пользователь выполняет 70 действий
        │
        ▼
Начисляется Locked-награда
        │
        ▼
Размер награды определяется уровнем Motherboard
        │
        ▼
Motherboard улучшается за Boost
        │
        ▼
Boost собираются 5 раз в сутки
        │
        ▼
Накопление Locked токенов
        │
        ▼
Burn Motherboard
        │
        ▼
Locked → Unlocked
        │
        ▼
Токены становятся доступны для перевода и продажи
```
